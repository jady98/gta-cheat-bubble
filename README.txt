GTA Cheat Bubble - proyecto Android

IMPORTANTE:
- Este proyecto es código fuente, NO un APK compilado.
- La burbuja y el panel flotante permiten seleccionar/copiar códigos.
- Android no permite que una app normal inyecte letras directamente en GTA.
- El botón COPIAR copia el texto al portapapeles; no activa el truco por sí solo.
- No modifica GTA ni sus partidas guardadas.
- La compatibilidad de los códigos con GTA San Andreas 2.11.311 no está garantizada.

Para compilar:
1. Abre el proyecto en Android Studio.
2. Espera la sincronización de Gradle.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Instala el APK generado en un dispositivo de prueba.
5. Abre la app, concede "Mostrar sobre otras aplicaciones" y activa la burbuja.

Este proyecto es una base inicial y debe compilarse y probarse en el dispositivo antes de usarlo.

COMPILAR SIN COMPUTADORA (GitHub Actions):
1. Abre la pestaña Actions del repositorio.
2. Si GitHub pregunta, habilita Actions.
3. Ejecuta "Build GTA Cheat Bubble APK" con Run workflow, o espera al flujo automático al subir a main.
4. Cuando termine correctamente, abre la ejecución y descarga el artefacto GTA-Cheat-Bubble-debug.
5. Descomprime el artefacto y encontrarás app-debug.apk.

La compilación remota requiere conexión a internet y una cuenta de GitHub. El APK debug no está firmado para distribución pública.
